Adaptive Model SDK

2026 Apr 20 · Model Routing, sdk

Building up on the ideas from KV-Lab and Adaptive Model Kit, I have been working on adaptive model sdk for last few days to take the idea beyond initial testing. Running amk on local Qwen3.5, Qwen2.5, Gemma4 and other specialist models.

Results have been encouraging as I continue to test.

  • amk orchestrator decides on model routing, based on query
  • models understand knowledge gaps, so there are intelligent fallbacks on generic models for final decision
  • gaps are actively looked upon by Autoresearcher loop that feeds back into knowledge gaps
  • smaller models run with added knowledge next time

Waiting to see if specialists models will be able to run at par with generic models cross-domain, using lower resources.

GitHub: https://github.com/dheerajbatra/adaptive-model-sdk
